## 可以逐步推进的三个研究练习

### 练习 A：拆开不同误差的影响

在固定的简单二维模型上，一次只改变一个参数：源区大小、角度数量或轨迹间距。各组都把源迭代误差压到足够小，再比较通量、反应率和时间。目标是找到当前设置下的主要误差来源，而不是在多个参数同时改变时笼统说“更精确”。

前置条件：教学 MOC 能保持守恒，且有独立参考解或可信基准；参考解也应说明精度。详细验证步骤见 [算法与验证路线](02-algorithm-and-validation.md)。

### 练习 B：平源与线性源的公平比较

读 P04 后，先固定材料数据、边界、角度与轨迹规则，再比较平源与线性源在不同源区大小下的误差、内存和总时间。比较目标可以是相同精度下的成本，或相同成本下的误差；两种目标不能混为同一结论。

前置条件：完整理解空间矩与源系数的更新，不仅替换段内公式。没有实现和复现前，本仓库只记录该研究问题。

### 练习 C：将扫描优化与迭代加速分开计时

对同一物理模型，单独记录几何追踪、MOC 扫描、源更新、CMFD 构建与求解的时间。比较“无加速 / 有加速”和“CPU / GPU”时，应说明精度、硬件、线程、算术精度、迭代停止条件，以及是否计入初始化。

前置条件：至少有一个稳定可用的求解器和合理的计时接口。第一次调研无需急于实现 GPU 或全堆模型。

## 每篇文章的阅读记录模板

复制下面模板为新的笔记文件，不要把摘要级摘记自动改成“全文精读”。

```markdown
# Pxx：文章题名

- DOI / 官方来源：
- 阅读日期与版本：
- 阅读范围：摘要 / 部分正文 / 全文 / 已复现
- 文件或原文链接：

## 它解决什么问题？

## 它对基础 MOC 改了什么？

## 输入、输出与关键假设

## 核心公式或算法步骤

## 使用了哪些基准与比较条件？

## 结果、证据位置与适用边界

## 我仍不理解的问题

## 对本项目的下一步启发
```

引用具体性能数字时同时记录表号、算例、硬件、基线和计时范围。自己的解释、推导和实验建议应与原文结论分开。

## 第一轮完成标准

- 能用自己的话解释段内指数解中的入口贡献与源贡献。
- 能说明平源、角度离散、轨迹积分和多群处理各带来什么近似。
- 能画出源更新、输运扫描、边界更新和特征值更新的关系。
- 能说清线性源、CMFD、即时追踪分别改进哪个环节。
- 能比较直接三维 MOC 与 2D/1D 的假设、资源与适用场景。
- 能为一项拟开展的实验写出可检验问题、控制变量、参考解和评价指标。
