# MOC 阅读路线：由浅入深

更新：2026-10-10。本路线按理解任务排序，不按发表年份排序。先建立“沿一条线怎么解、许多线怎么合成、源为什么要迭代”的框架，再读改进论文。每篇完整书目、来源与查阅范围见[文献目录](../references/literature.md)，全文位置见[获取状态](../references/download-status.md)。

## 1. 先走核心路线

**本仓库基础调研 → R01 → P02 → P01 的中子输运部分 → P04 → CMFD 文档/P10 → P05 → P06。**

P01 是跨领域综述，可用来建立数学背景；首次接触反应堆 MOC 时，R01 和 P02 的具体公式通常更容易与计算流程对应。若暂时没有 P01、P04、P05 或 P06 的全文，先沿免费材料建立框架，再通过学校订阅补读，核心学习不必停在全文获取环节。

免费起步材料：本仓库[调研正文](01-moc-survey.md)、[OpenMOC 官方理论文档](https://mit-crpg.github.io/OpenMOC/methods/index.html)、[P02 作者稿](../papers/pdf/P02_Boyd_2014_OpenMOC_author-manuscript.pdf)、[P10 正式 PDF](../papers/pdf/P10_Song_2020_GPU_Two_Level_CMFD_published.pdf)和[MPACT 4.4 手册](../papers/pdf/R03_MPACT_2023_Theory_Manual_4.4.pdf)。手册先按需查阅，不要求从头读完199页。

## 2. 分阶段读什么，读到什么程度？

### 阶段 A：看懂输运方程和一条特征线

**先读：** [术语表](glossary.md) → [初版调研第1–4节](01-moc-survey.md) → [R01 的特征线推导](https://mit-crpg.github.io/OpenMOC/methods/method_of_characteristics.html)。

**为什么这样读：** 在研究程序和并行之前，先理解角通量、标量通量、源与截面的关系。特征线上的解析段解是后续所有实现的基础。

**重点：** 链式法则、光学厚度、入口贡献与段内源贡献、平源与常数截面假设、真实飞行距离。首遍可以暂缓线性源和高阶散射展开。

**读后交付：** 独立推导出口及段平均角通量；算一个无源吸收例子与一个有源例子；说明FSR为什么不等于通量处处常数。

### 阶段 B：看懂完整二维 MOC

**顺序：** [P02 OpenMOC论文](../references/literature.md#p02) → [R01 轨迹生成](https://mit-crpg.github.io/OpenMOC/methods/track_generation.html) → [R01 特征值计算](https://mit-crpg.github.io/OpenMOC/methods/eigenvalue_calculations.html) → [P01 综述的基础及中子输运部分](../references/literature.md#p01)。

**为什么读P02：** 它把公式、几何、轨迹、扫描、源更新和基准验证连接起来，是本轮主线。先读方法与验证设置，性能结果作为第二遍阅读内容。

**为什么补P01：** 把具体中子计算放回特征线方法的数学背景。它包含其他物理应用，首遍无需逐一读完。

**选读P03：** [教材章节](../references/literature.md#p03)可提供另一套组织方式和符号，适合有电子书访问权限时补充；当前没有归档正文，因此不设为免费核心路线的门槛。

**读后交付：** 画扫描与源迭代流程；解释方向权重和轨迹空间权重；列出能群、空间源、角度、轨迹和迭代误差。若准备编程，再读[算法与验证](02-algorithm-and-validation.md)。

### 阶段 C：理解空间精度和收敛加速

**顺序：** [P04 线性源](../references/literature.md#p04) → [R01 CMFD](https://mit-crpg.github.io/OpenMOC/methods/cmfd.html) → [P10 两级CMFD与GPU](../references/literature.md#p10)。

**为什么先读P04：** 它改进源在空间中的表示，帮助区分“空间阶数提高”与“轨迹更多”。关注空间矩与源梯度如何更新。

**为什么再读CMFD/P10：** 它们帮助理解为什么扫描正确但源迭代仍可能慢。P10有公开正式全文，还可观察加速层线性求解器的成本。

**读后交付：** 为“更高源阶数”“更少扫描次数”“更快单次扫描”分别写出作用环节；设计相同精度下的成本比较。不能只比较一个速度倍数。

### 阶段 D：理解三维路线与建模假设

**顺序：** [P05 直接三维与模块追踪](../references/literature.md#p05) → [P06 2D/1D稳定性与精度](../references/literature.md#p06) → [R03 MPACT手册](../papers/pdf/R03_MPACT_2023_Theory_Manual_4.4.pdf)相关章节。

**为什么读P05和P06：** 前者介绍直接三维轨迹与资源组织，后者介绍径向/轴向耦合的另一条路线。两篇形成方法假设和工程成本的对照。

**读后交付：** 对照表列出径向与轴向描述、源近似、泄漏耦合、几何条件、存储与验证。说明为什么2D/1D不能当成彼此独立的二维切片。

到这里可形成一份基础课程调研。后续选择一个分支，不必同时深入全部方向。

## 3. 按研究兴趣选择进阶分支

| 分支 | 建议顺序 | 为什么读 | 应形成的结果 |
|---|---|---|---|
| 三维全堆与真实模型 | P07 → R05 → R03按需查阅 | 看基础算法如何处理BEAVRS规模，核对几何、工况和验证来源 | 模型/离散/资源/验证四栏表 |
| 复杂几何 | P05复习 → P08 | 对照重复单元复用与非结构网格追踪 | 适用几何与求交、通信成本说明 |
| CPU/GPU与性能 | P09 → P10复习 → P11 | 依次看内核组织、迭代与硬件组合、少群三维显存管理 | 统一误差与基线的性能记录表 |
| 粗网加速与快堆 | CMFD复习 → P12 | 观察六角形快堆中的粗网连通及能群粗化 | 精细模型与加速层的关系图 |
| 随机射线与抽样 | P13 → P14 | 从固定轨迹积分进入随机轨迹及重要性抽样 | 抽样对象、权重、统计误差与成本说明 |
| 三维相关中文扩展 | P06复习 → P15 | 用中文资料理解高阶轴向展开与特征面 | 明确特征面、特征线与2D/1D的区别 |

P11、P12、P14是本轮选取的较新案例，不意味着完成了全部2025–2026年文献覆盖。它们应在基础方法之后读。P15研究特征面，放在相关扩展分支，而不是当作平源MOC的入门介绍。

## 5. 建议的第一轮产出

可以用四轮学习推进：一轮推导单段公式，一轮梳理二维算法和误差，一轮比较线性源/CMFD，一轮对照三维路线。每轮读到能回答任务即可，时间根据数学与反应堆物理基础调整。

每篇至少记录：解决什么问题、改了哪个环节、假设是什么、用什么参考验证、证据在何处、还有什么不理解。复制[阅读记录模板](research-questions.md)。引用性能数字时同时保留算例、硬件、基线与计时范围。

完成第一轮的判断标准：能从输运方程推到单段解，能画源迭代循环，能解释主要误差，能区分空间改进、收敛改进与硬件改进，并能为一个拟开展的实验提出可检验问题。
