# 教学演示验证记录

日期：2026-10-10。对应[交互页面](../demo/index.html)和[教学讲义](../docs/03-moc-tutorial.md)。

## 数值验证

执行 `node --test tests/teaching.test.cjs`，9组检查全部通过。测试直接读取HTML中 `moc-engine` 脚本的函数，所以没有另外复制一份计算实现。

| 检查 | 独立依据或性质 |
|---|---|
| 无源、有源及平衡单段 | 指数解析解；q = Σt ψ时保持常数 |
| 透明、零长和薄段 | 连续极限及小光学厚度展开 |
| 段平衡与拆段 | 积分守恒；同一材料分成两段应保持出口与整体平均 |
| 分层和斜射 | 入口/出口连续连接；60°斜射距离为法线厚度两倍 |
| 圆形轨迹几何 | 中心弦长2r、方形边界、段长分割、90°旋转一致性 |
| 两方向散射模型 | 独立联立全部界面方向通量与区域平均通量方程，直接求线性系统，不使用源迭代 |
| 无散射真空平板 | 对连续指数解作区域平均，并检查吸收与泄漏 |
| 未收敛源的平衡 | 积分方程中的旧散射源与新通量差 |
| 一格源迭代 | 几何递推固定点；迭代上限不足时正确返回未收敛 |

直接线性系统对比包含1、8、20个源区，散射比例0、0.5、0.95，以及|μ|=1和1/√3。它验证的是相同平源、两个方向的离散问题，不是以相同离散问题代替连续角度参考。

- 加载与操作没有JavaScript页面错误；运行没有外部网络请求。

## 复算

有Node.js时，在仓库根目录运行：

```text
node --test tests/teaching.test.cjs
node examples/generate-results.cjs
```

第二步生成[结果JSON](../examples/teaching-results.json)，记录参数、归一化约定、迭代历史和平衡，以及数值脚本的SHA-256。**学习界面本身不需要安装Node.js**，下载HTML后直接在浏览器打开即可。

当前没有开展多群、裂变特征值、二维完整通量、三维或C5G7/BEAVRS工程基准复现；这些是已有[验证设计](../docs/02-algorithm-and-validation.md)中的后续阶段。
