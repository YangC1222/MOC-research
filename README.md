# MOC 中子输运调研

一套面向初学者、逐步深入到算法与研究问题的中文资料。这里的 **MOC** 指 **Method of Characteristics（特征线法）**，应用对象是中子输运与反应堆物理。

本仓库包含阅读顺序、文献来源、每篇资料的阅读理由、初版调研笔记，以及经过来源和许可核验的部分原文。整理更新：**2026-10-10**；首轮检索与书目核验：2026-10-09。本轮整理了 **15 篇论文/章节、5 项官方辅助资源、5 份可分享原文 PDF**。这是持续更新的学习型调研，尚未开展自编求解器或数值复现。

## 从这里开始

1. 阅读 [阅读路线](docs/reading-plan.md)，选择核心路线或完整路线。
2. 阅读 [MOC 初版调研：从物理到研究进展](docs/01-moc-survey.md)，先形成整体认识。
3. 对照 [OpenMOC 官方理论说明](https://mit-crpg.github.io/OpenMOC/methods/index.html)，逐步理解特征线变换、段内积分、轨迹生成、源迭代和 CMFD。
4. 按路线阅读 [文献目录与阅读理由](references/literature.md)。每篇文献具有稳定编号 `P01`–`P15`。
5. 如准备编程，阅读 [算法与验证路线](docs/02-algorithm-and-validation.md)。

最短入门路线：**术语 → 特征线公式 → 平源 MOC → 几何追踪与源迭代 → 误差与验证 → 线性源与 CMFD → 三维及 2D/1D → 并行与近期扩展**。具体先读哪些文章、读后应能回答什么，见阅读路线。

## 如何使用这套资料

- **做课程调研或展示**：先读核心路线，能够讲清 MOC 为什么成立、如何计算、误差来自哪里，再选择一个改进方向。
- **准备写程序**：先做分层介质特征线传播与源迭代，再扩展二维轨迹及多群问题；用独立参考解与网格、方向、轨迹收敛检查验证。
- **寻找研究方向**：从源近似、收敛加速、三维几何、追踪存储、并行计算中选择一个问题；先固定比较条件与证据，再讨论改进。

## 来源与原文

参考文献以 DOI、出版社、开发团队、研究机构和基准组织的官方记录为主要来源。文献条目的 `reading_basis` 区分摘要、官方说明和已查阅原文；网页或摘要级介绍不等同于完成全文精读。

本次只处理**论文正文**，不下载 Supporting Information。公开可读与可再次分享并非同一条件：只归档能够核验分享依据的原文，保持原文件和版权声明；其他条目保留 DOI 与合法全文入口。各文件的版本和许可分别见 [获取状态](references/download-status.md) 与 [原文清单](papers/manifest.json)。

本仓库的学习笔记不替代原论文，也不改变第三方原文的许可。引用方法、实验结果或性能数字时，应引用对应论文并保留其算例、硬件和比较基线。
